# Cartera ONUDI Costa Rica 2026

Plataforma interactiva del Programa País ONUDI–Costa Rica 2024–2028.

## Desarrollo local

Requiere Node.js 22 o superior.

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Publicación en Vercel

1. Suba esta carpeta a un repositorio de GitHub.
2. En Vercel, seleccione **Add New → Project**.
3. Importe el repositorio.
4. Use **Next.js** como Framework Preset.
5. Mantenga `npm run build` como Build Command.
6. Presione **Deploy**.

No requiere variables de entorno ni base de datos.
